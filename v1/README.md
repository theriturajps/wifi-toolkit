This Python script creates fake Wi-Fi networks (Evil Twin) with the same SSID as a target network. It allows

- Single Fake AP – Mimic a single Wi-Fi network (open or password-protected).
- Bulk Creation – Load multiple SSIDs from a `.txt` or `.lst` file.
- Password Monitor – Detect handshake attempts (Scapy-based).
- Admin Check – Ensures script runs with elevated privileges.
